# Inter font source

`Inter-Variable.woff2` is the upright variable WOFF2 from the official Inter
4.1 release:

- Project: https://github.com/rsms/inter
- Release: https://github.com/rsms/inter/releases/tag/v4.1
- Archive path: `web/InterVariable.woff2`
- Supported weight axis: 100–900

The unmodified font is redistributed under the SIL Open Font License 1.1 in
`OFL.txt`.
