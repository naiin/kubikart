# Montserrat font source

`Montserrat-Variable.woff2` is the Latin variable WOFF2 distributed by
Google Fonts from the official Montserrat family:

- Family source: https://github.com/google/fonts/tree/main/ofl/montserrat
- Upstream project: https://github.com/JulietaUla/Montserrat
- Distributed webfont version: Google Fonts Montserrat v31
- Supported weight axis: 100–900

The unmodified font is redistributed under the SIL Open Font License 1.1 in
`OFL.txt`.
